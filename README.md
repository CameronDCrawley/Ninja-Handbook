# Naruto API 

A simple Node.js and Express API that serves information about various ninjas from popular shinobi villages, complete with support for CORS and static file serving.

## Features

 **RESTful Endpoint:** Fetch specific ninja details by name.

---

## Prerequisites

Make sure you have Node.js installed on your machine.

---
## Install dependencies:
npm install express cors

---
## Run the application:
node server.js

---
## API Endpoints
Home Page
Endpoint: GET /

Description: Serves the main HTML frontend file.

## Get Ninja Details
Endpoint: GET /api/:ninjaName

Description: Returns a JSON object containing details about a specific ninja (such as their age, signature ability, and village).

## Built With
Node.js - JavaScript runtime environment

Express - Fast, unopinionated web framework for Node.js

CORS - Node.js package for providing a Connect/Express middleware that can enable CORS
